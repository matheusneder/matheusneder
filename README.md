# Hi, I'm Matheus Neder

I'm a computer engineer from Brazil with more than 20 years of experience building software and designing system architectures. I started in 2003 as a freelance web developer and Linux sysadmin. Since then, I've worked in product development, software engineering and solutions architecture, much of it at banks, where security, reliability and governance shape every decision.

A lot of that work has been about changing systems that can't stop. At Banco Mercantil and Itaú Unibanco, I designed architectures for moving mainframe systems to the cloud while the old and new applications ran side by side. At Olé Consignado (Santander Brasil), I led the solutions architecture team and helped roll out one of the first on-premises Kubernetes clusters in Belo Horizonte.

Today I'm a Software Engineering Specialist at TOTVS. You can read the full story at [www.matheusneder.com](https://www.matheusneder.com).

## What I'm working on

At TOTVS, I designed and built a component that interprets and rewrites SQL at runtime, so applications written for Microsoft SQL Server can also run on Oracle Database and PostgreSQL. It uses AI for the complex statements that fixed translation rules don't cover well, and existing customizations keep their compatibility and performance. I also support TOTVS Cloud operations, working on availability, performance and incident response.

## What I do

- **Solutions architecture and legacy modernization:** gradual migrations from mainframes to the cloud, hybrid architectures and integration between legacy and new systems.

- **AI applied to software engineering:** in products, like the SQL rewriting above, and in everyday development, with spec-driven development (SDD).
- **Engineering practices:** DDD, TDD, code reviews and mentoring developers.
